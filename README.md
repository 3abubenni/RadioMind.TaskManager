### AI-Powered Content Orchestration Service
**Java 21 • Quarkus • Maven**

Сервис автоматизирует создание контента с помощью ИИ. Принимает сырые данные в формате JSON, инициирует AI-обработку через асинхронные задачи и формирует готовые посты на основе обогащенных данных.

**Ключевые функции:**  
🎯 **Конвейер обработки данных**
- Приём входящих JSON-данных через REST API (`/api/data`)
- Автоматическое создание AI-задач (например, классификация) при получении новых данных
- Пагинированное управление данными и задачами

🤖 **Интеграция с ИИ**
- Гибкая система задач (поддерживает разные типы: `CLASSIFICATION`, `GENERATION` и др.)
- Асинхронная обработка через независимые AI-модули
- Механизм отслеживания статусов задач (`PENDING`, `PROCESSING`, `COMPLETED`)

⚙️ **Технологический стек:**
- Java 21
- Quarkus
- Hibernate ORM с Panache
- Lombok
- Maven
- OpenAPI-документация

**Примеры использования:**
1. Сбор данных из внешних источников (новости, соцсети)
2. Автоматическая рубрикация контента через ИИ
3. Генерация постов для блогов/SMM на основе структурированных данных

**Запуск:**
```bash
mvn quarkus:dev
```
